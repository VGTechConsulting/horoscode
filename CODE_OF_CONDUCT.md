# Code of Conduct

## The short version

Be decent. Assume the other person is trying to make the project better, and argue
about the work rather than about them.

## What that means here

Most of this repository is arguments — about how code gets verified, what a posture
costs, and which of eighteen names fits. Disagreement is the point, and a well-made
case against a decision is welcome even when the decision stands. What is not welcome:

- Harassment, insults, or personal attacks, in issues, pull requests, or commits.
- Demeaning comments about anyone's identity, background, experience, or the way they
  write code.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing anyone's private information without permission.
- Sustained disruption — reopening settled questions to make a point, or brigading a
  thread.

None of that is softened by being right about the technical question.

## Scope

This applies in every project space — issues, pull requests, discussions, commit
messages, and code review — and to anyone taking part, maintainers included.

## Enforcement

Report a problem by [opening a private security advisory][report], which is the one
private channel this repository has, or by contacting a maintainer directly. Reports
are handled discreetly and the reporter's identity is not shared with the person
reported.

Maintainers may edit or remove contributions that do not follow this document, and may
block a participant. For anything beyond a first, minor incident, expect a block
rather than a negotiation.

[report]: https://github.com/VGTechConsulting/horoscode/security/advisories/new
